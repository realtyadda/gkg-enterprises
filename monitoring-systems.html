SELECTION GUIDE

Start with the application.

01

From instrument to information

A monitoring arrangement may include field sensors, transmitters, a controller or data logger, communications and a display or supervisory system. The final architecture depends on the site.

02

Signals and communications

Common interface choices can include analogue signals, relay contacts and digital protocols, but support varies by product. Confirm wiring, protocol, addressing, network and cybersecurity requirements.

03

System design considerations

Review measurement points, cable runs, power availability, environmental protection, data intervals, alarms, reporting, calibration access and future expansion.

04

Plan your system enquiry

Provide a point list, parameter and range per point, site layout, existing PLC/SCADA or BMS details, preferred protocol, power/network constraints and desired reports.

Technical guidance only. Confirm exact specifications, certifications, compatibility, availability and suitability against the selected manufacturer's current documentation before procurement or installation.

QUICK ANSWERS

Frequently asked
questions.

Can sensors from different manufacturers work together?

Sometimes, when electrical interfaces, protocols, ranges and configuration are compatible. Confirm end-to-end compatibility before purchase.

Does this page describe a ready-made package?

No. It is a planning guide; final scope and compatibility must be established for the application.

Can the system support remote monitoring?

Remote access depends on the selected hardware, network architecture, software and site security policies.
