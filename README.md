# GKG Enterprises website

A lightweight, responsive static website built for GitHub Pages.

## Current stage

Phase 1 establishes the homepage, initial product-category framework, application sections, technical-support preview, and enquiry checklist. It does **not** yet publish verified OEM partnerships, model-specific specifications, downloadable datasheets, or live contact actions.

## Structure

- `index.html` — homepage and main navigation
- `assets/css/style.css` — responsive styling
- `assets/js/main.js` — accessible mobile navigation and dynamic footer year
- `robots.txt` — crawler rules; sitemap reference will be added after the production domain is confirmed

## GitHub Pages

In the repository, open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/ (root)`, then save. GitHub Pages deployment may take a few minutes. The expected project-site address is:

`https://realtyadda.github.io/gkg-enterprises/`

This address is expected from the repository name; confirm it in the Pages settings after deployment.

## Before public launch

1. Confirm the final domain and configure it in GitHub Pages, if applicable.
2. Confirm the business phone, WhatsApp number and enquiry email.
3. Confirm actual product categories and initial models.
4. Verify OEM names, authorised-partner status, specifications, photos and datasheets before publishing.
5. Add product detail pages, technical FAQs, accurate structured data, canonical URLs and sitemap for the final domain.
6. Test navigation, mobile layouts, links, accessibility and page loading on phone and desktop.

## Contact form note

GitHub Pages serves static files and does not process form submissions or run server-side code. This version does not pretend that a form has been submitted. Live enquiry actions will be configured once approved business contact details are provided; a form that stores submissions would require an external form service or backend.

## Hosting note

GitHub Pages has usage policies and is not intended as free hosting for a business website primarily directed at facilitating commercial transactions. Review GitHub's current Pages terms before relying on it for ongoing commercial use.
